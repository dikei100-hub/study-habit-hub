## 1. 하루 경계 (가장 중요)

- 하루는 자정이 아니라 **새벽 4시**에 바뀐다.
- `04:00 ~ 다음날 03:59` 는 **같은 날**로 친다.
- 이유: 밤 12시를 넘겨 공부한 것을 전날 기록으로 잡기 위함. 야간 사용자 배려.
- 계산은 **`src/lib/studyDay.ts` 의 `getStudyDate()` 한 곳에서만** 한다.
  - 다른 파일에서 `new Date().toISOString().slice(0,10)` 같은 직접 계산 금지.
  - 규칙이 바뀔 때 한 파일만 고치면 되도록 유지한다.

## 2. 두 목록의 체크박스는 의미가 다르다 ★

가장 헷갈리는 지점이므로 반드시 구분할 것.

| | 리스트 관리 시트 | 오늘의 할 일 |
|---|---|---|
| 체크박스 의미 | **매일 할지 말지** (on/off) | **오늘 했는지** (완료 여부) |
| 지속성 | 한 번 켜두면 계속 유지 | 날짜마다 새로 시작 |
| 연동 | **서로 연동되지 않는다** | |

- 오늘의 할 일을 완료해도 리스트 관리의 체크는 그대로다.
- 리스트 관리에서 체크를 켜면 → 그 날짜의 할 일에 **미완료 상태로** 추가된다.
- 리스트 관리에서 체크를 끄면 → 그 날짜의 할 일에서 사라진다.

---

## 3. 리스트 관리 시트

- 오늘 화면과 캘린더 화면의 "리스트 관리" 버튼으로 연다.
- 화면 전환이 아니라 **아래에서 올라오는 시트(bottom sheet)**.
- **대상 날짜**: 오늘 화면에서 열면 오늘, 캘린더에서 열면 선택된 날짜.

### 동작

- **추가**: 새 항목은 **목록 맨 위**에 넣는다. 맨 아래 아님.
  (목록이 길어지면 아래는 찾기 어렵기 때문)
  새 항목은 on 상태로 시작하고, 대상 날짜의 할 일에도 즉시 나타난다.
  빈 문자열·공백만 입력은 추가하지 않는다.
- **체크박스**: 2번 항목 참고 (매일 할지 말지).
- **휴지통**: 목록에서 **완전 제거**. 대상 날짜의 할 일에서도 함께 사라진다.

### 이 앱의 전제

매일 같은 일을 반복하는 사용자를 위한 앱이다.
그래서 이 목록이 기준이 되고, 매일 그대로 넘어간다.

---

## 4. 오늘의 할 일

- 각 항목에 **삭제 버튼**이 있다.
- 삭제하면 **그 날짜에서만** 빠진다.
- 리스트 관리 목록은 건드리지 않으므로 **다음 날 다시 나타난다.**
  (예: "오늘은 학원 가서 못 하니까 빼자" → 내일은 다시 나옴)

---

## 5. 새 날 채우기

앱이 어떤 날짜에 진입했을 때:

1. 그 날짜의 할 일이 **하나라도 있으면** → 아무것도 하지 않는다. (중복 방지)
2. **하나도 없으면** → 리스트 관리 목록에서 **on 상태인 항목들**을
   그 날짜의 할 일로 복사한다. **모두 미완료 상태.**
3. on 상태인 항목이 하나도 없으면 빈 목록으로 시작한다.

- 며칠 안 열었다가 열어도 **그날 것만** 만들면 되므로 단순하다.
- 각 날짜의 인스턴스는 독립이다. 오늘 체크해도 내일 것은 새로 미완료로 깔린다.

## 6. 날짜별 편집 규칙

| 날짜 | 완료 체크 | 항목 추가/삭제 | 리스트 관리 버튼 |
|------|-----------|----------------|------------------|
| **과거** | 불가 | 불가 | 숨김 |
| **오늘** | 가능 | 가능 | 표시 |
| **미래** | 불가 | 가능 | 표시 |

- 과거 날짜는 **그날 무엇을 했고 무엇을 안 했는지 확인하는 용도**다.
- 미래는 미리 계획만. 완료는 그날이 되어야 한다.

## 7. 화면 구성

### 탭 (하단 고정, 4개)

```
오늘  /  통계  /  캘린더  /  보상
```

- 안드로이드판은 상단 탭이지만, **웹은 하단**이다. iOS 한 손 조작 고려.
- 선택된 탭은 연보라 배경의 둥근 사각형으로 강조. 아이콘 위, 글자 아래.
- **설정은 탭에 없다.** 각 화면 오른쪽 위 톱니 아이콘으로 진입.

### iOS 대응

- `index.html` viewport 에 `viewport-fit=cover`
- 탭바에 `env(safe-area-inset-bottom)`, 본문 상단에 `env(safe-area-inset-top)`
- 본문 최대 폭 420px, 가운데 정렬. 모바일 전용.

### 색상 (한 곳에 정의, 컴포넌트에 직접 쓰지 말 것)

| 용도 | 값 |
|------|-----|
| 배경 | 아주 옅은 라벤더 `#F4F1FA` |
| 기본 카드 | 흰색 |
| 강조 카드 | 연보라 `#E8DFF7` |
| 보조 카드 | 연하늘 `#D6E8FA` / 연노랑 `#FBEFB0` / 연분홍 `#FBDCE4` |
| 포인트·링·막대 | 보라 `#B39DE0` ~ `#6B4FA8` |
| 제목 글자 | 짙은 보라빛 회색 `#4A4458` |
| 할 일 항목 | 연두 `#DCF0DC` / 하늘 `#D6E8FA` / 살구 `#FBE3D0` 순환 |
| 체크박스 | 초록 `#34C759` |

### 톤

- 카드 라운드 20px 내외, 아주 옅은 그림자, 테두리 없음.
- 글자 크게, 여백 넉넉하게, 정보 밀도 낮게.
- 문구는 **"관리"가 아니라 "응원"**. 지시형 대신 격려형.
- 마스코트(햄스터)와 배지 이미지는 **아직 없다.** 원형 placeholder로 자리만 잡는다.

## 8. 보상 규칙

### 코인

- **하루 100% 달성 시 +10코인.** 하루에 한 번만.
- 부분 달성(75% 등)에는 지급하지 않는다. 목표는 "완주".
- 이미 100% 달성해 받은 뒤 할 일을 추가했다가 다시 100%를 만들어도 추가 지급 없음.

### 스트릭 (연속 기록)

- **연속으로 "하루 100% 달성"한 날의 수.**
- 100%를 못 하고 넘어가면 0으로 초기화.
- 저장값이 아니라 **기록에서 매번 재계산**한다. 소급 수정에도 자동 정합.

### 트로피 (상점형, 코인으로 구매)

| 트로피 | 가격 |
|--------|------|
| 브론즈 | 100코인 |
| 실버 | 300코인 |
| 골드 | 600코인 |

- 순서대로만 구매 가능. (브론즈 → 실버 → 골드)

### 배지 (조건형, 행동으로만 획득)

| 배지 | 조건 |
|------|------|
| 첫걸음 | 첫 완벽 달성 |
| 첫 연속 | 3일 연속 달성 |
| 연속 7일 | 7일 연속 달성 |
| 연속 30일 | 30일 연속 달성 |
| 연속 100일 | 100일 연속 달성 |
| 완벽한 주 | 한 주 완벽 달성 |
| 완벽 마스터 | 완벽한 날 50일 |
| 공부왕 | 누적 100개 완료 |
| 독서광 | 누적 300개 완료 |
| 학습 마스터 | 누적 500개 완료 |
| 열공왕 | 하루 5개 이상 100일 |
| 첫 트로피 | 트로피 첫 구매 |

- **한 번 획득하면 취소하지 않는다.** 조건이 다시 false여도 유지.
- 미획득 배지도 목록에 회색으로 다 보이게 한다.
- 큰 목표는 리셋되는 '연속'보다 쌓이는 '누적'이 친절하다.
  (하루 놓쳐도 진행이 유지되어야 습관 앱 취지에 맞음)

### 스트릭 프리즈 — 웹판 미구현

안드로이드판에는 있으나 웹판에는 아직 없다. 나중에 붙일 때 `RewardSystemDesign.md` 4장 참고.

## 9. 데이터 저장

- 저장소 접근은 **`src/lib/storage.ts` 를 통해서만** 한다.
  다른 파일에서 `localStorage` 직접 호출 금지.
- 현재는 브라우저 localStorage. **나중에 Supabase로 교체 예정**이므로
  이 파일 하나만 고치면 갈아탈 수 있는 구조를 유지한다.
- 값이 없거나 깨진 경우에도 앱이 죽지 않고 초기값으로 시작할 것.

## 10. 알려진 이슈 (2026-08-21 기준, 미해결)

우선순위 순.

1. **시드 데이터가 `{ year: 2026, month: 8, today: 19 }` 로 고정.**
   9월이 되면 어긋난다. 실제 날짜 기준으로 바꿔야 함.
2. **캘린더 월 이동 버튼(◀ ▶)이 동작하지 않음.** UI만 있고 핸들러 없음.
3. **통계의 "이전 7일보다 +73%"가 하드코딩.** 계산값으로 교체 필요.
4. **보상 탭이 정적.** 배지·트로피가 실제 달성 데이터와 연결되어 있지 않음.
5. **컬렉션 화면 미구현.** "내 컬렉션 모두 보기" 버튼만 있고 화면이 없음.
6. `src/components/ui/` 의 shadcn 컴포넌트 49개는 미사용 자산.
   앱 화면은 전부 `components/app/` + 순수 Tailwind로 만들어짐.
