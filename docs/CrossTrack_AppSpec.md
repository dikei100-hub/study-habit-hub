# StudyMate — 앱 사양서 (웹/iOS 판 담당 AI에게)

StudyMate("공부체크") 안드로이드판의 **화면·기능 사양**을 플랫폼 중립적으로 정리한 것입니다.
웹(→iOS) 판의 **뼈대(구조·화면·흐름)** 를 만들 때 이 문서를 기준으로 삼으세요.
특정 언어·프레임워크·코드 없이 "무엇을 만드는가"만 담았습니다.

- **보상/스트릭/배지의 정확한 계산 규칙**은 이 문서에 반복하지 않습니다 → 짝 문서 **`CrossTrack_Lessons.md` 3장**을 반드시 함께 보세요.
- 디자인 시안 이미지(파스텔 톤 + 햄스터 마스코트)가 있으면 함께 참고하세요.

---

## 1. 앱 개요 & 컨셉

- **한 줄:** 고등학생이 하루 공부 목표를 세우고 체크하며 습관을 만드는 앱.
- **컨셉:** **"관리가 아니라 응원."** 다그치지 않고, 작은 성취도 인정하고 북돋운다.
- **핵심 루프:** 그날 할 일을 담는다 → 하나씩 완료 체크한다 → 진행률·연속·배지·코인으로 성취를 시각화하고 응원받는다 → 다음 날 반복.
- **톤:** 부드럽고 귀엽고 따뜻함. 게임적 보상은 있지만 압박이 아니라 격려 수단.

---

## 2. 디자인 언어

- **팔레트:** 파스텔 위주. 항목 카드에 순환하는 4색(연초록·연파랑·연복숭아·연노랑), 포인트 색으로 연보라/라벤더, 마스코트 배경에 연분홍. 배경은 아주 옅은 라벤더빛 흰색.
- **강조/상태 색:** 상승=부드러운 초록, 하락=부드러운 코랄. 달력의 일요일=차분한 빨강, 토요일=차분한 파랑(공휴일도 빨강).
- **마스코트:** 햄스터 캐릭터. 상황에 따라 표정/포즈가 다른 여러 버전(기본 인사, 축하, 졸업모자 등)을 화면 맥락에 맞게 사용. 살짝 커졌다 작아지는 "숨쉬기" 애니메이션으로 생동감.
- **형태:** 둥근 모서리 카드, 은은한 그림자, 넉넉한 여백. 요소들이 "말랑한 카드"처럼 보이게.
- **애니메이션(과하지 않게):** 체크할 때 살짝 "통통" 튐, 진행률/도넛이 "차오름", 색이 부드럽게 전환, 마스코트 숨쉬기. 절제해서 사용.
- **문구 톤:** 반말·존댓말 섞인 다정한 응원체("조금씩 해도 충분해!", "오늘도 힘내자!", "잘하고 있어요!").

---

## 3. 정보 구조 & 네비게이션

- **하단 탭 4개:** **오늘 · 통계 · 캘린더 · 보상.** (아이콘 + 라벨.)
- **설정 화면은 없다.** (초기 시안엔 5번째 탭으로 있었으나 **의도적으로 제거** — 7장 참고.)
- 단일 화면 앱 느낌. 탭 전환이 주 내비게이션. 별도 상세 화면은 캘린더의 "그날 상세"와 공용 "리스트 관리" 모달 정도.

---

## 4. 화면별 사양

### 4-1. 오늘 (홈)
그날의 할 일을 완료 체크하는 메인 화면.
- **상단 캐릭터 헤더:** 마스코트 + 달성률에 따라 3단계로 반응(시작 전 / 진행 중 / 목표 달성)하는 인사말·말풍선. 예: "오늘도 힘내자!" → "잘하고 있어요!" → "오늘 목표 달성!".
- **오늘 달성률:** 큰 퍼센트 숫자 + "N / M 완료" + 진행률 바.
- **연속(스트릭) 문구:** "🔥 N일 연속 공부 중 · 최고 M일"(연속이 0이면 "오늘부터 시작해봐요" 류). *시안엔 없던 응원 요소로 추가함.*
- **할 일 목록:** 카드형 항목들. **카드 아무 곳이나 탭하면 완료 토글**(체크 이모지가 통통 튀고, 완료 시 카드가 그 항목 색으로 채워지며 "완료" 표기). 길게 누르면 부가 동작(선택).
- **할 일 담기:** "리스트 관리" 모달로 진입(4-5 참고). *일회성 "+추가"는 의도적으로 없앰 — 7장.*

### 4-2. 통계
성취를 한눈에 보여주고 응원하는 화면.
- **연속 카드 + 마스코트 카드**(나란히): 왼쪽은 현재 연속 일수(🔥) — 최고 기록이면 "최고 기록!" 배지, 오른쪽은 마스코트 + "꾸준함이 힘이에요!". 연속이 실제로 끊긴 상태에서 방어(프리즈) 가능하면 "지키기" 버튼과 함께 "연속이 끊겼어요"로 표시(표시 규칙은 Lessons 3장).
- **최근 7일 달성률:** 막대그래프(날짜별 %).
- **이번 주 달성률:** 도넛 + 지난 7일 대비 증감(▲초록/▼코랄/동일 중립) + "N / M 완료".
- **이번 달 달성률:** 도넛 + "총 N / M 완료"(이번 달 1일~오늘, 미래 제외).
- **하단:** 앱 버전 한 줄.

### 4-3. 캘린더
월 단위로 달성 이력을 보고, 특정 날짜의 할 일을 관리.
- **월 헤더 + 이월(◀▶), 요일 헤더**(주말/공휴일 색 구분).
- **날짜 격자:** 각 날짜에 **달성률 링(도넛)**. 채움 비율로 그날 달성률 표현, 링 안에 % 텍스트. 오늘은 굵게, 선택한 날은 원 채움 강조.
- **선택한 날짜 상세(격자 아래):** "N / M 완료" 요약 + 그날 할 일 목록.
  - **과거 = 읽기 전용**(완료 못 바꿈), **오늘 = 완료 토글 가능**, **미래 = 완료 불가, 할 일 목록 구성(리스트 관리)만 가능.**
  - 오늘·미래 날짜엔 "리스트 관리" 버튼 노출.
- 달성률 공식은 통계와 **동일**(정합성).

### 4-4. 보상
코인·배지·트로피로 동기를 부여하는 화면.
- **상단 코인 잔액.**
- **칭찬 카드**(마스코트 + 응원 메시지).
- **배지 목록(격자):** 획득/미획득(잠금)을 모두 표시. 현재 배지 구성(난이도·계열별):
  - 첫걸음(첫 완벽 달성), 첫 연속(3일 연속)
  - 열공 7일 / 열공 30일 / 열공 100일 (공부한 날 누적)
  - 완벽한 주(최근 7일 연속 100%), 완벽 마스터(완벽한 날 50일)
  - 노력왕(누적 100개) → 성실왕(300개) → 공부왕(500개) [누적 완료 개수]
  - 공부의 신(하루 5개 이상 완료한 날 100일)
  - 첫 트로피(트로피 첫 구매)
  - *각 배지는 고유 일러스트를 가짐. 이름·그림·난이도가 정렬돼야 함(Lessons 1·2장).*
- **연속/프리즈 카드:** 방어 가능 시 "지키기(코인 50)" 버튼. (통계와 같은 프리즈 개념.)
- **코인 상점(트로피):** 코인으로 등급형 트로피(브론즈→실버→골드) 구매. 이전 등급을 보유해야 다음 구매 가능.

### 4-5. 리스트 관리 (공용 모달/다이얼로그)
"오늘"과 "캘린더"에서 공용으로 쓰는, **그 날짜의 할 일 목록을 구성**하는 모달.
- 상단: 제목 + 닫기(X), 마스코트 + "조금씩 해도 충분해!" 응원 한 줄, "체크하면 그 날짜 할 일에 바로 나타나요" 안내.
- **입력줄:** 텍스트 입력 + 키보드 완료/엔터로 바로 추가(별도 "+" 버튼 없음).
- **항목 목록:** 반복 루틴 "템플릿" 목록. 각 항목을 **탭하면 그 날짜 목록에 담기/빼기**(체크 = 담김, 카드가 그 색으로 채워짐). 각 항목에 삭제(휴지통) 버튼(템플릿 자체 삭제).
- 비어 있을 때: "첫 할 일을 적어볼까요?" 류의 부드러운 안내.
- **개념 핵심:** 여기서 체크는 "완료"가 아니라 **"그 날짜에 이 할 일을 올릴지"**(담기/빼기)다. 실제 완료 체크는 "오늘" 화면(또는 캘린더의 오늘)에서 한다.

## 5. 핵심 데이터 개념 (플랫폼 무관)

구현 스키마는 자유지만, 아래 개념이 필요합니다.

- **할 일 템플릿(반복 루틴):** 사용자가 만든 할 일 정의(제목 등). "리스트 관리"에서 관리.
- **날짜별 배치(방식 A):** 템플릿을 **특정 날짜에 인스턴스화**해 "그날의 할 일"을 만든다. 그날 처음 열 때 1회 생성(중복 방지). → 과거 날짜의 할 일은 그날 상태로 보존된다. (자세한 설계 의도는 원본 기획의 "날짜별 할 일" 문서 개념 참고.)
- **날짜별 기록:** 날짜마다 1건 — 그날 완료 개수, 전체 개수, 완벽 여부(그날 100%), 방어(프리즈)됨 여부, 그날 코인 지급됨 여부.
- **보상 상태:** 코인 잔액, 현재 연속, 최고 연속, 보유 트로피, 프리즈 관련 날짜 등.
- **배지:** 배지별 획득 여부(+획득일). **내부 식별자와 표시 이름을 분리**하라(Lessons 2장).
- **원칙:** 연속·배지·달성률은 **저장값이 아니라 기록에서 매번 재계산**한다(Lessons 3-4).

## 6. 핵심 플로우

1. **하루 완료 루프:** 리스트 관리로 오늘 할 일 담기 → "오늘"에서 항목 탭해 완료 → 달성률/연속/코인/배지 갱신(정산 순서: 코인→연속→배지, Lessons 3-9).
2. **날짜별 관리:** 캘린더에서 미래 날짜 선택 → 리스트 관리로 그날 할 일 미리 구성. 과거는 읽기 전용.
3. **연속 방어(프리즈):** 어제를 놓쳤고 조건 충족 시 "지키기" 제안 → 코인 50으로 어제를 방어 → 연속 복구(적용 순서·원자성은 Lessons 3-6,3-7).
4. **트로피 구매:** 보상 화면 상점에서 코인으로 등급 트로피 구매(선후행 조건).

## 7. 의도적으로 뺀 것 (웹판에서 다시 넣지 말 것)

- **설정 화면/5번째 탭:** 제거. 알림·테마·백업·프로필은 후순위이며, 이름 없이도 인사말이 자연스러워 프로필 불필요로 판단. → 4탭으로 확정.
- **상단 알림 벨 아이콘:** 제거. 실제 알림 기능이 없어 껍데기 아이콘은 오해를 준다.
- **일회성 "+추가" 버튼:** 제거. 반복 템플릿을 날짜에 담는 "리스트 관리" 방식(방식 A)으로 통일.
- (이유를 이해하고, 웹판에서 정말 필요하면 그때 별도 결정하라.)

## 8. 웹/iOS 뼈대 만들 때 권장 순서

1. **디자인 토큰 먼저:** 파스텔 팔레트 상수 + 공통 카드/버튼/도넛/진행률 컴포넌트 + 마스코트 자리. (화면마다 색·여백 하드코딩 금지 — 나중에 지옥.)
2. **네비게이션 뼈대:** 하단 4탭 + 빈 화면 4개.
3. **데이터 개념 스텁:** 5장의 개념을 최소 형태로. "오늘 날짜"·"하루 인정 조건"·"완벽 판정"은 **각각 한 곳에서만** 정의(Lessons 부록).
4. **오늘 화면 → 리스트 관리 → 캘린더 → 통계 → 보상** 순으로 살 붙이기.
5. **보상/연속 로직은 마지막에, `CrossTrack_Lessons.md` 3장을 그대로 규칙서로 삼아** 구현. 습관 축(하나라도 함)과 완벽 축(다 함)을 처음부터 분리.
