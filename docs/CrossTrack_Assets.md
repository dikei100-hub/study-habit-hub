# StudyMate — 이미지 에셋 목록 & 반영 가이드 (웹/iOS 판)

안드로이드판의 **이미지 에셋(마스코트·배지·트로피·앱아이콘)** 목록과, 웹판에서 어디에 넣어야 하는지를 정리한 문서입니다.
현재 웹판 스크린샷의 **빈 원(placeholder)** 자리에 아래 이미지들이 들어가야 합니다.
`CrossTrack_AppSpec.md`(화면·기능), `CrossTrack_Lessons.md`(규칙)와 함께 쓰세요.

> **★ 가장 중요한 주의:** 배지 이미지의 **파일명은 옛 코드(레거시)라 현재 이름과 다릅니다.**
> 예: `badge_streak_7.png`는 지금 "열공 7일" 배지, `badge_study_100.png`는 지금 "공부왕" 배지입니다.
> **파일명을 믿지 말고, 아래 매핑 표를 기준**으로 각 배지 슬롯에 연결하세요.

---

## 0. 파일이 있는 폴더 (전달용)

- 마스코트(홈 표정들): `.../res/drawable/` 안의 `char_*.png`
- 배지·트로피·졸업 마스코트·아이콘 원본: `.../res/drawable-nodpi/` 안의 `badge_*.png`, `trophy_*.png`, `char_graduate.png`, `ic_hamster_foreground.png`
- 앱 아이콘(런처): `.../res/mipmap-*/ic_launcher*.webp` (여러 해상도)

모두 **래스터 이미지(PNG, 아이콘만 WEBP)** 입니다. 웹에선 그대로 쓰거나 필요시 WEBP로 변환하세요. 배지·트로피·졸업 마스코트는 고해상도(nodpi)라 확대에 유리합니다.

---

## 1. 마스코트 (햄스터 캐릭터)

앱의 마스코트는 **햄스터**입니다. 화면 맥락에 따라 표정/포즈가 다른 버전을 씁니다. 앱에선 마스코트를 **파스텔 원형 배경 안에** 담아 보여줍니다(웹도 동일 권장).

### 실제 사용 중
| 파일 | 무엇 | 어디에 쓰이나 (웹 슬롯) |
|---|---|---|
| `char_hello.png` | 기본 인사 햄스터 | **홈 상단 캐릭터(시작 전 단계)** + 리스트 관리 모달의 작은 마스코트 |
| `char_good.png` | 기운찬 햄스터 | **홈 상단 캐릭터(진행 중 단계)** |
| `char_congrats.png` | 축하하는 햄스터 | **홈 상단 캐릭터(목표 달성 단계)** + 보상 화면 상단 "칭찬 카드" |
| `char_graduate.png` | 졸업모자 쓴 햄스터 | **통계 화면 "꾸준함이 힘이에요!" 카드** + 보상 화면 마스코트 |

> 홈 캐릭터는 그날 달성률에 따라 **hello → good → congrats** 3단계로 바뀝니다(같은 자리, 이미지·문구 교체).

### 예비(현재 미사용, 넘겨주면 나중에 활용 가능)
`char_angry.png`, `char_panic.png`, `char_sad.png`, `char_sleepy.png`, `char_thanks.png`, `char_wow.png` — 추가 표정들. 지금 화면엔 안 쓰지만, 웹판에서 상황별 반응을 더 풍부하게 하고 싶을 때 쓸 수 있음.

### 쓰지 말 것 (옛 버전)
`char_person_hello.png`, `char_person_good.png`, `char_person_congrats.png` — **사람 캐릭터(구버전).** 햄스터로 교체되기 전 것이므로 **웹판에서 사용하지 마세요.**

## 2. 배지 (12종) — ★ 파일명 ≠ 현재 이름, 아래 표가 기준

각 배지는 고유 일러스트를 가집니다. 보상 화면 "획득한 배지"/"내 컬렉션" 격자에서, 그리고 획득 알림에서 씁니다. 미획득은 잠금(흐릿하게) 표시.

| 파일 | 현재 배지 이름 | 획득 조건(개념) |
|---|---|---|
| `badge_first_step.png` | 첫걸음 | 첫 완벽(그날 100%) 1회 |
| `badge_streak_3.png` | 첫 연속 | 3일 연속(실제 연속) |
| `badge_streak_7.png` | **열공 7일** | 공부한 날 누적 7일 |
| `badge_streak_30.png` | **열공 30일** | 공부한 날 누적 30일 |
| `badge_streak_100.png` | **열공 100일** | 공부한 날 누적 100일 |
| `badge_perfect_week.png` | 완벽한 주 | 최근 7일 모두 100% |
| `badge_perfect_50.png` | 완벽 마스터 | 완벽한 날(100%) 누적 50일 |
| `badge_study_10.png` | **노력왕** | 누적 완료 100개 |
| `badge_study_50.png` | **성실왕** | 누적 완료 300개 |

> 굵게 표시한 것들이 파일명과 이름이 특히 다른 배지입니다(옛 코드명 유지). 조건 계산 규칙은 `CrossTrack_Lessons.md` 3장 참고.

## 5. 웹판 반영 체크리스트

- [ ] 현재 웹판의 **빈 원(placeholder)** 을 위 이미지로 교체:
  - 홈 상단 캐릭터 → `char_hello/good/congrats`(달성률 3단계).
  - 통계 "꾸준함이 힘이에요!" 카드 → `char_graduate`.
  - 보상 상단 칭찬 카드 → `char_congrats`(또는 `char_graduate`).
  - 보상 배지 격자 → 배지 12종(2번 매핑표대로).
  - 보상 트로피 → 트로피 3종.
- [ ] 마스코트는 **파스텔 원형 배경 안에** 넣어 앱 톤 유지.
- [ ] 배지는 **파일명이 아니라 2번 표의 "현재 이름"으로** 슬롯 연결(레거시 파일명 함정 주의).
- [ ] 미획득 배지/트로피는 잠금(흐릿) 상태로 표시.
- [ ] `char_person_*`(사람 캐릭터, 구버전)는 사용하지 않기.
- [ ] 이미지 라이선스/저작권은 원작자(앱 소유자) 판단에 따름 — 재사용 가능 여부 확인 후 사용.
