# 기능 명세서 (Functional Specification)

## 1. 문서 목적 및 범위

### 1.1 문서 목적

본 문서는 StudyMate의 MVP-Core 기능이 **무엇을, 언제, 어떻게** 동작해야 하는지를 개발·검증
관점에서 명확히 정의하는 것을 목적으로 합니다. 화면의 시각적 구성은
[ScreenDesign.md](ScreenDesign.md)에서, 데이터 구조는 [Database.md](Database.md)에서 다루며,
본 문서는 **동작(behavior)과 규칙(rule)** 에 집중합니다.

### 1.2 명세 범위

이번 명세는 [PRD.md](PRD.md)의 **6. 기능 범위** 중 **MVP-Core** 기능만 포함합니다.

| ID | 기능 | 대응 PRD 항목 |
|----|------|---------------|
| F-CHAR | 기본 캐릭터 표시 | 기본 캐릭터 표시 |
| F-TODO | 오늘의 할 일 체크리스트 | 오늘의 할 일 체크리스트 |
| F-FEED | 달성률/완료 피드백 | 달성률/완료 피드백 |
| F-STREAK | 연속 기록(스트릭) | 연속 기록(스트릭) |
| F-REWARD | 기본 보상(배지·코인) | 기본 보상(배지·코인) |
| F-STORE | 로컬 데이터 저장 | 로컬 데이터 저장 |

MVP-Next 및 추후 확장 기능(통계, 캘린더, 레벨·캐릭터 성장, 템플릿, 다크 모드, 위젯, 서버
동기화 등)은 본 명세의 범위 밖이며 **5. 이번 명세 범위 밖**에 정리합니다.

### 1.3 표기 규칙

- **기능 ID:** `F-XXX` 형식으로 각 기능을 식별한다.
- **요구사항 ID:** 각 기능 내 개별 규칙은 `F-XXX-01`처럼 번호를 붙여 추적 가능하게 한다.
- **용어:** 굵게 표기된 용어(예: **달성률**)는 **2. 핵심 용어 정의**를 따른다.
- **수용 기준:** 각 기능 말미의 "수용 기준"은 해당 기능이 완료로 인정되기 위한 검증 조건이다.
- 본 문서는 오프라인·단일 기기·로컬(Room) 저장을 전제로 한다(PRD 10. 제약 및 가정).

## 2. 핵심 용어 정의

| 용어 | 정의 |
|------|------|
| **할 일(Task)** | 사용자가 하루 단위로 등록하는 개별 공부 목표 항목. 예: "수학 문제집 10쪽". |
| **오늘(Today)** | 기기의 로컬 날짜 기준 당일. 날짜 경계는 로컬 자정(00:00)으로 한다. |
| **완료(Done)** | 할 일 항목이 체크되어 실천이 이루어진 상태. 반대 상태는 **미완료**. |
| **달성률** | 오늘 등록된 전체 할 일 중 완료된 항목의 비율. `완료 수 ÷ 전체 수 × 100(%)`. |
| **완료 피드백** | 항목 완료 시 즉시 제공되는 애니메이션·칭찬 메시지 등 즉각적 반응. |
| **연속 기록(스트릭, Streak)** | 하루의 **실천 조건**을 만족한 날이 끊기지 않고 이어진 연속 일수. |
| **실천 조건** | 스트릭이 하루 인정되는 조건. MVP-Core에서는 "당일 최소 1개 이상 할 일 완료"로 정의한다. |
| **코인(Coin)** | 실천에 따라 즉시 적립되는 게임 내 재화. MVP-Core에서는 적립·누적만 다룬다. |
| **배지(Badge)** | 특정 조건을 달성하면 획득하는 성취 보상. 한 번 획득하면 영구 보존된다. |
| **응원 메시지** | 캐릭터가 홈에서 전달하는 격려·칭찬 문구. |
| **캐릭터(마스코트)** | 홈 화면에서 사용자를 맞이하고 응원하는 기본 캐릭터. MVP-Core에서는 성장 없이 표시만 한다. |
| **로컬 저장소** | 네트워크 없이 기기 내부에 데이터를 보관하는 Room 기반 저장소. |

## 3. 기능 간 동작 관계

MVP-Core 기능들은 **"할 일 완료"라는 단일 사용자 행동**을 중심으로 연쇄적으로 반응합니다.

### 3.1 핵심 흐름

```
[F-TODO] 할 일 완료(체크)
   │
   ├─▶ [F-FEED]  즉시 완료 피드백(애니메이션·칭찬) + 달성률 재계산
   │
   ├─▶ [F-REWARD] 코인 적립, 배지 조건 검사 및 획득
   │
   ├─▶ [F-STREAK] 당일 첫 완료 시 실천 조건 충족 → 스트릭 갱신
   │
   └─▶ [F-STORE]  위 모든 상태 변화를 로컬 저장소에 즉시 반영
```

앱 실행 시 **[F-CHAR]** 캐릭터가 홈에서 사용자를 맞이하고 응원 메시지를 표시하며, 이는 다른
기능의 상태(달성률·스트릭 등)를 참조해 문구를 선택할 수 있습니다.

### 3.2 의존 관계 요약

| 기능 | 직접 의존(입력) | 영향(출력) |
|------|-----------------|------------|
| F-CHAR | F-STORE(오늘 상태 조회) | 응원 메시지 표시 |
| F-TODO | F-STORE | 달성률, 완료 이벤트 발생 |
| F-FEED | F-TODO(완료 이벤트) | 시각 피드백, 달성률 표시 |
| F-STREAK | F-TODO(완료 이벤트), F-STORE | 연속 일수 갱신 |
| F-REWARD | F-TODO(완료 이벤트), F-STORE | 코인·배지 상태 갱신 |
| F-STORE | 전 기능 | 영속 데이터 제공 |

### 3.3 공통 원칙

- **단일 진실 원천:** 모든 상태(할 일·달성률·스트릭·코인·배지)의 최종 저장처는 **F-STORE**이다.
- **즉시 반영:** 완료 행동에 따른 피드백·보상·스트릭 변화는 사용자가 체감할 수 있도록 즉시(같은
  프레임 흐름 내) 처리한다.
- **날짜 경계 일관성:** "오늘"의 판정은 모든 기능에서 로컬 자정 기준으로 동일하게 적용한다.

## 4. 기능 명세

### 4.1 F-CHAR — 기본 캐릭터 표시

**개요**
홈(오늘) 화면 상단에 기본 캐릭터(마스코트)가 표시되어 사용자를 맞이하고 응원 메시지를 전달한다.
MVP-Core에서는 캐릭터 성장·레벨 없이 **표시와 응원**만 담당한다.

**동작 규칙**

- `F-CHAR-01` 홈 화면 진입 시 기본 캐릭터가 항상 표시된다.
- `F-CHAR-02` 캐릭터와 함께 **응원 메시지**가 1개 노출된다.
- `F-CHAR-03` 응원 메시지는 앱 실행/홈 진입 시점에 결정되며, 오늘의 상태를 참조해 상황에 맞는
  문구를 선택할 수 있다. 예: 미완료 상태 → "오늘도 화이팅!", 일부 완료 → "잘하고 있어요!",
  전체 완료 → "오늘도 해냈어요!".
- `F-CHAR-04` 참조할 상태가 없거나 첫 실행인 경우 기본 인사 문구를 표시한다.

**입력 / 출력**

- 입력: 오늘의 달성률·완료 여부(F-STORE 조회, 선택적).
- 출력: 캐릭터 이미지, 응원 메시지 텍스트.

**예외 / 엣지**

- 상태 조회 실패 시에도 캐릭터와 기본 인사 문구는 반드시 표시한다(빈 화면 금지).

**수용 기준**

- 홈 진입 시 캐릭터와 응원 메시지가 항상 함께 보인다.
- 오늘의 완료 상태에 따라 응원 문구가 달라지는 것을 확인할 수 있다.

---

### 4.2 F-TODO — 오늘의 할 일 체크리스트

**개요**
사용자가 오늘 해야 할 공부 목표를 **등록·완료·삭제**하고, 실시간으로 **달성률**을 확인하는 핵심
기능이다.

**동작 규칙**

- `F-TODO-01` 사용자는 할 일 항목을 **추가**할 수 있다. 항목은 최소한 제목(내용) 텍스트를 가진다.
- `F-TODO-02` 제목이 비어 있는 항목은 등록할 수 없다(공백만 입력 시 등록 불가).
- `F-TODO-03` 사용자는 항목을 **체크하여 완료** 처리하거나, 체크를 해제하여 **미완료**로 되돌릴 수
  있다.
- `F-TODO-04` 사용자는 항목을 **삭제**할 수 있다.
- `F-TODO-05` 오늘 화면에는 **오늘 날짜**에 해당하는 항목만 표시된다.
- `F-TODO-06` 항목의 추가/완료/미완료/삭제 결과는 즉시 화면에 반영되고 F-STORE에 저장된다.
- `F-TODO-07` **달성률**은 `완료 수 ÷ 전체 수`로 계산하며, 상태가 바뀔 때마다 재계산된다.
  전체 수가 0이면 달성률은 0%로 표시한다.
- `F-TODO-08` 날짜가 바뀌면(로컬 자정 경과) 새 날짜의 목록은 비어 있는 상태로 시작한다. 과거
  날짜의 항목은 삭제되지 않고 기록으로 보존된다.

**입력 / 출력**

- 입력: 할 일 제목, 체크/해제 조작, 삭제 조작.
- 출력: 오늘의 할 일 목록, 각 항목의 완료 상태, 오늘의 달성률(%).

**연계 이벤트**

- 항목 완료 시 **완료 이벤트**를 발생시켜 F-FEED, F-REWARD, F-STREAK를 트리거한다.
- 완료된 항목을 다시 미완료로 되돌리는 경우의 보상 처리 규칙은 F-REWARD·F-STREAK 항목을 따른다.

**예외 / 엣지**

- 동일 제목의 항목 중복 등록은 허용한다(사용자가 의도적으로 반복 목표를 둘 수 있음).
- 목록이 비어 있을 때는 빈 상태 안내를 표시하며 달성률은 0%로 둔다.

**수용 기준**

- 추가·완료·해제·삭제가 모두 정상 동작하고 즉시 저장된다.
- 완료 상태 변경에 따라 달성률이 정확히 갱신된다.
- 앱을 재실행해도 오늘의 목록과 완료 상태가 유지된다.

### 4.3 F-FEED — 달성률/완료 피드백

**개요**
할 일 완료 시점에 **즉각적인 시각 피드백과 칭찬 메시지**를 제공하고, **달성률**을 시각적으로
보여 주어 성취감을 준다.

**동작 규칙**

- `F-FEED-01` 항목을 완료하면 즉시 완료 애니메이션(부드러운 체크/카드 전환 등)이 재생된다.
- `F-FEED-02` 완료 시 짧은 **칭찬 메시지**(예: "잘했어요!")를 함께 노출한다.
- `F-FEED-03` **달성률**은 게이지/진행 표시로 시각화되며, 완료·해제에 따라 즉시 값이 갱신된다.
- `F-FEED-04` 오늘의 **전체 항목을 모두 완료**하면 일반 완료보다 강조된 축하 피드백을 제공한다.
- `F-FEED-05` 피드백은 화면 조작을 막지 않으며, 짧게 표시된 후 자연스럽게 사라진다.

**입력 / 출력**

- 입력: F-TODO의 완료 이벤트, 현재 달성률.
- 출력: 완료 애니메이션, 칭찬 메시지, 달성률 시각 표시.

**예외 / 엣지**

- 빠르게 연속으로 여러 항목을 완료해도 피드백이 겹쳐 끊기지 않고 자연스럽게 처리되어야 한다
  (PRD 10. 제약: 부드러운 애니메이션 성능 요건).
- 완료를 해제하는 경우 완료 애니메이션·칭찬은 재생하지 않고 달성률만 갱신한다.

**수용 기준**

- 완료 즉시 애니메이션과 칭찬 메시지가 나타난다.
- 달성률이 완료/해제에 맞춰 실시간으로 정확히 반영된다.
- 전체 완료 시 강조 축하 피드백이 나타난다.

---

### 4.4 F-STREAK — 연속 기록(스트릭)

**개요**
매일 실천을 이어갈 때 **연속 일수(스트릭)** 를 계산·표시하여 꾸준함을 시각화한다.

**동작 규칙**

- `F-STREAK-01` **실천 조건**은 "당일 최소 1개 이상 할 일 완료"로 정의한다.
- `F-STREAK-02` 실천 조건을 처음 만족하는 순간(당일 첫 완료) 해당 날짜가 실천일로 기록된다.
- `F-STREAK-03` 어제 실천이 있었고 오늘 새로 실천하면 스트릭이 **1 증가**한다.
- `F-STREAK-04` 어제 실천이 없고(하루 이상 공백) 오늘 실천하면 스트릭은 **1로 초기화**된다.
- `F-STREAK-05` 실천이 없는 날이 지나 다음 실천이 발생하기 전까지, 끊긴 스트릭은 다음 실천
  시점에 재계산된다.
- `F-STREAK-06` 현재 연속 일수는 홈/보상 영역에서 확인할 수 있다.
- `F-STREAK-07` 당일 유일한 완료 항목을 다시 **미완료로 되돌려** 완료 항목이 0이 되면, 그날의
  실천 기록은 취소되고 스트릭도 취소 이전 상태로 되돌린다.

**입력 / 출력**

- 입력: 당일 완료 항목 존재 여부, 직전 실천일 기록(F-STORE).
- 출력: 현재 연속 일수, 최근 실천일.

**예외 / 엣지**

- 날짜 판정은 로컬 자정 기준이며, 기기 시간 변경 등으로 발생할 수 있는 경계 문제는 "오늘" 정의
  (2장)를 일관되게 적용하여 처리한다.
- 같은 날 여러 항목을 완료해도 스트릭은 하루에 1일만 인정한다.

**수용 기준**

- 연속으로 실천한 날 수만큼 스트릭이 정확히 증가한다.
- 하루라도 실천이 없으면 다음 실천 시 스트릭이 1로 초기화된다.
- 앱 재실행 후에도 스트릭 값이 유지된다.

---

### 4.5 F-REWARD — 기본 보상(배지·코인)

**개요**
실천에 따라 **코인**을 즉시 적립하고, 조건을 만족하면 **배지**를 획득하게 하여 성취감과 동기를
부여한다. MVP-Core에서는 보상의 **적립·획득·표시**를 다루며, 코인 사용(소비)은 범위 밖이다.

**동작 규칙**

- `F-REWARD-01` 할 일 항목을 완료하면 정해진 양의 **코인**이 즉시 적립되고 누적 코인에 더해진다.
- `F-REWARD-02` 완료한 항목을 다시 **미완료로 되돌리면** 해당 완료로 적립된 코인을 회수하여
  중복·부당 적립을 방지한다(적립과 회수는 대칭적으로 동작).
- `F-REWARD-03` **배지**는 사전에 정의된 조건을 만족하는 순간 자동으로 획득된다. MVP-Core 기본
  배지 조건 예시:
  - 첫 할 일 완료
  - 하루 전체 완료(오늘의 모든 항목 완료)
  - 스트릭 특정 일수 도달(예: 3일 연속)
- `F-REWARD-04` 배지는 **최초 1회만** 획득되며, 이미 보유한 배지는 중복 획득되지 않는다.
- `F-REWARD-05` 배지 획득 순간 획득 사실을 사용자에게 알린다(획득 피드백).
- `F-REWARD-06` 누적 코인과 획득 배지 목록은 보상 영역에서 확인할 수 있다.

**입력 / 출력**

- 입력: 완료/해제 이벤트, 달성률, 스트릭 일수, 기존 코인·배지 상태(F-STORE).
- 출력: 갱신된 누적 코인, 신규 획득 배지 및 획득 알림.

**예외 / 엣지**

- 배지 조건 판정은 완료 이벤트가 반영된 **이후 상태**를 기준으로 한다.
- 미완료 되돌림으로 조건이 다시 깨지더라도, 이미 획득한 배지는 회수하지 않는다(획득은 영구).

**수용 기준**

- 완료 시 코인이 적립되고, 되돌리면 대칭적으로 회수된다.
- 정의된 조건 충족 시 배지가 1회 획득되고 알림이 표시된다.
- 누적 코인·배지 상태가 앱 재실행 후에도 유지된다.

---

### 4.6 F-STORE — 로컬 데이터 저장

**개요**
모든 핵심 데이터를 **네트워크 없이 로컬(Room)** 에 저장하여, 오프라인에서도 기능이 완전히
동작하고 앱 재실행 후에도 상태가 보존되도록 한다.

**동작 규칙**

- `F-STORE-01` 다음 데이터를 로컬에 영속 저장한다: 할 일 항목(내용·날짜·완료 여부), 날짜별
  달성/실천 기록, 스트릭 상태, 누적 코인, 획득 배지.
- `F-STORE-02` 상태를 변경하는 모든 동작(추가/완료/해제/삭제/보상 적립 등)은 즉시 로컬에
  반영된다.
- `F-STORE-03` 앱을 종료 후 재실행해도 마지막 저장 상태가 그대로 복원된다.
- `F-STORE-04` 모든 기능은 네트워크 연결 없이 정상 동작한다(오프라인 우선, PRD 10. 제약).
- `F-STORE-05` 과거 날짜의 기록은 임의로 삭제되지 않고 보존된다(향후 통계·캘린더 기능의 기반).

**입력 / 출력**

- 입력: 각 기능의 상태 변경 요청.
- 출력: 저장된 영속 데이터의 조회 결과.

**예외 / 엣지**

- 저장 실패 시 사용자 데이터가 유실되지 않도록 처리하며, 화면 상태와 저장 상태의 불일치를 남기지
  않는다.
- 스키마 세부 정의 및 마이그레이션 규칙은 [Database.md](Database.md)를 따른다.

**수용 기준**

- 네트워크가 없는 상태에서 모든 MVP-Core 기능이 동작한다.
- 앱 재실행 후 할 일·달성률·스트릭·코인·배지가 모두 복원된다.

## 5. 이번 명세 범위 밖

아래 항목은 이번 MVP-Core 명세에 **포함하지 않으며**, 이후 사이클에서 별도로 명세한다.
(근거: [PRD.md](PRD.md) 6. 기능 범위 및 9. Out of Scope)

### 5.1 MVP-Next (다음 단계에서 명세 예정)

- **통계 및 성장 그래프** — 일간/주간/월간 집계와 성장 추이 시각화.
- **캘린더 기록 조회** — 날짜별 달성 기록 확인.
- **레벨·캐릭터 성장** — 실천에 따른 레벨 상승 및 캐릭터 성장(본 명세의 F-CHAR는 표시만 담당).
- **목표 템플릿 관리** — 자주 쓰는 할 일 템플릿 저장·재사용.
- **다크 모드** — 라이트/다크 테마 전환.

### 5.2 추후 확장 (장기 로드맵)

- 홈 위젯, 서버 계정·클라우드 동기화, 친구·랭킹 등 소셜 요소, 캐릭터·테마 상점, 사용자층 확장.

### 5.3 코인 사용(소비)

- MVP-Core에서는 코인의 **적립·누적·표시**만 다룬다. 코인을 사용하는 상점/소비 기능은 범위 밖.

### 5.4 명시적 제외 항목 (PRD 9. Out of Scope)

- 성적/시험 점수 관리·분석, 학습 콘텐츠 제공, 결제·인앱 구매, 서버 로그인, 소셜 기능,
  학부모·교사용 모니터링, Android 외 플랫폼 지원.
