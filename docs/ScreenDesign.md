## 1. 개요

본 문서는 StudyMate의 **화면 설계 기준 문서**입니다. 각 화면의 역할, 구성 요소,
표시 데이터, 그리고 개발 우선순위(MVP 단계)를 정의하여 UI 구현의 기준으로 삼습니다.

- **시안 기준:** [design/screen_concept_v1.png](../design/screen_concept_v1.png) 를 기준으로 작성합니다.
- **디자인 방향:** iPhone 스타일의 **미니멀 · 파스텔 톤 · 둥근 카드 · 부드러운 애니메이션**을 지향합니다.
- **관련 문서:** 제품 요구사항은 [PRD.md](PRD.md), 상세 기능 명세는 [FunctionalSpec.md](FunctionalSpec.md)를 참고합니다.

각 화면 설명에는 PRD의 MVP 단계 구분(**Core / Next / 추후 확장**)을 함께 표기하여
개발 우선순위가 드러나도록 합니다.

## 2. 화면 구성 원칙

- **총 5개 화면**으로 구성하며, **좌우 스와이프(슬라이드)** 와 상단/하단 네비게이션으로 이동합니다.
- **여백이 넉넉한 레이아웃**과 **둥근 카드(Rounded Card) 기반 UI**를 사용합니다.
- **파스텔 톤**을 기본으로 하고, **보라색을 포인트 컬러**로 사용합니다.
- **귀여운 곰 마스코트(캐릭터)** 가 응원과 성취의 정서적 경험을 전달합니다.
- 사용자가 앱을 열면 **오늘 화면이 가장 먼저 크게** 보입니다.
- 체크 · 보상 · 화면 전환은 **끊김 없는 부드러운 애니메이션**으로 동작합니다.
- **라이트 / 다크 모드**를 함께 고려합니다. (다크 모드는 MVP-Next 단계)

## 3. 네비게이션 구조

5개 화면은 아래 순서로 배치되며, **좌우 스와이프(HorizontalPager)** 로 이동합니다.

```
오늘  →  통계  →  캘린더  →  보상  →  설정
 ✓        📊       📅        🏆       ⚙️
```

| 순서 | 화면 | 아이콘 | 한 줄 역할 |
|------|------|--------|-----------|
| 1 | 오늘 | ✓ | 오늘 해야 할 일 확인 · 체크하고 목표 달성 |
| 2 | 통계 | 📊 | 주간/누적 통계와 성장 그래프를 한눈에 |
| 3 | 캘린더 | 📅 | 날짜별 달성률 · 과거 기록 조회 |
| 4 | 보상 | 🏆 | 칭찬 · 배지로 동기부여, 코인으로 꾸미기 |
| 5 | 설정 | ⚙️ | 앱 설정과 템플릿 관리로 나만의 앱 만들기 |

- 화면을 **왼쪽으로 드래그**하면 다음 화면으로, **오른쪽으로 드래그**하면 이전 화면으로 이동합니다.
- 상단(또는 하단)에 **현재 위치를 나타내는 페이지 인디케이터(점)** 를 표시합니다.
- 상단 네비게이션의 화면 아이콘을 눌러 해당 화면으로 바로 이동할 수 있습니다.

## 4. 화면별 상세

각 화면은 상단 상태바(시간·상태 아이콘)와 화면 제목을 공통으로 가지며, 아래 항목을 정의합니다.

### 4.1 오늘 화면

> **역할:** 앱의 첫 화면. 캐릭터의 응원과 함께 오늘 할 일을 확인 · 체크하고 달성률을 즉시 확인한다.

**구성 요소**

- **헤더:** 화면 제목("오늘")과 알림 벨 아이콘.
- **인사말:** "안녕하세요, {이름}! 👋" 형태의 개인화된 인사.
- **응원 말풍선 + 마스코트:** 캐릭터가 "오늘도 정말 잘하고 있어! 끝까지 화이팅! 💪🌟" 같은 응원 메시지를 전달.
- **오늘 목표 달성률:** 큰 퍼센트 수치(예: 75%)와 진행률 바, "6 / 8 완료" 형태의 요약.
- **오늘 해야 할 일:** 섹션 제목과 "+ 추가" 버튼.
- **할 일 체크리스트:** 과목 아이콘 + 항목명 + 완료 체크박스로 구성된 둥근 카드 리스트. 완료 항목은 "완료" 표시.
- **페이지 인디케이터:** 하단 점 표시.

**MVP 단계**

- **Core:** 캐릭터 표시 · 응원 메시지, 할 일 체크리스트, 달성률/완료 피드백.
- **Next:** 목표 템플릿에서 불러오기("+ 추가" 확장), 레벨·캐릭터 성장 반영.

### 4.2 통계 화면

> **역할:** 학습 기록과 성장 추이를 시각화하여 "쌓이고 있다"는 성장 실감을 준다.

**구성 요소**

- **헤더:** 화면 제목("통계")과 도움말(?) 아이콘.
- **이번 주 달성률:** 큰 퍼센트 수치(예: 82%)와 라인 그래프, "지난 주보다 12% 증가!" 같은 변화 메시지.
- **연속 달성(스트릭):** "8일 🔥"과 "최고 기록!" 표시.
- **이번 주 완료:** "24 / 29 🎯" 형태의 완료량 요약.
- **최근 7일 달성률:** 날짜별 막대 차트(7/19 ~ 7/25).
- **전체 완료율:** 도넛 차트(예: 78%)와 "총 312 / 400 완료" 누적 요약.

**MVP 단계**

- **Core:** 연속 기록(스트릭) 시각화.
- **Next:** 통계 및 성장 그래프(달성률 추이, 주간 막대, 전체 완료율).

### 4.3 캘린더 화면

> **역할:** 날짜별 달성 기록을 캘린더에서 한눈에 확인하고 과거를 돌아본다.

**구성 요소**

- **헤더:** 화면 제목("캘린더").
- **월 네비게이션:** "2025년 7월"과 좌우 이동 화살표.
- **요일 헤더:** 일 ~ 토.
- **월간 캘린더 그리드:** 날짜마다 **달성률 링(원형 게이지)** 과 퍼센트를 표시(기록 없는 날은 "-").
- **선택 날짜 강조:** 선택한 날짜(예: 17일, 75%)를 포인트 컬러로 강조.
- **선택 날짜 상세:** "7월 17일 (목) 6 / 8 완료" 형태의 요약.

**MVP 단계**

- **Next:** 캘린더 기록 조회(월간 그리드, 날짜별 달성 링, 선택 날짜 상세) 전체가 다음 단계.

### 4.4 보상 화면

> **역할:** 칭찬과 배지로 성취감을 강화하고, 코인으로 꾸미기 동기를 만든다.

**구성 요소**

- **헤더:** 화면 제목("보상")과 보유 코인(예: 🪙 120).
- **칭찬 카드:** "오늘 목표를 75%나 달성했어요! 정말 대단해요! 🎉" 같은 칭찬 메시지와 하트를 표현하는 마스코트.
- **획득한 배지:** "모두 보기 >" 링크와 배지 목록(예: 연속 7일, 완벽 달성, 아침형 인간, 노력상).
- **다음 보상까지:** 목표 조건(예: "목표 달성률 90% 달성 시")과 진행률 바("82 / 90%"), 선물 아이콘.
- **코인 사용하기:** "테마 변경, 캐릭터 구매 등에 사용해보세요!" 안내와 진입 버튼.

**MVP 단계**

- **Core:** 기본 보상(배지 · 코인) 획득, 칭찬 메시지.
- **Next:** 레벨·캐릭터 성장 반영.
- **추후 확장:** 코인 상점(캐릭터·테마 구매).

### 4.5 설정 화면

> **역할:** 프로필과 앱 설정을 관리하여 나만의 앱으로 만든다.

**구성 요소**

- **헤더:** 화면 제목("설정").
- **프로필:** 프로필 이미지, 이름(예: "지민이"), 학년(예: "고등학교 2학년").
- **목표 템플릿 관리:** 자주 쓰는 공부 목표 템플릿 저장 · 편집 진입.
- **알림 설정:** 리마인더 등 알림 on/off.
- **테마 설정:** 라이트 / 다크 테마 선택(현재값 표시, 예: "라이트").
- **데이터 백업 / 복원:** 로컬 데이터 백업 및 복원.
- **앱 정보:** 버전 정보(예: "버전 1.0.0").

**MVP 단계**

- **Core:** 로컬 데이터 저장 기반의 기본 설정, 앱 정보.
- **Next:** 목표 템플릿 관리, 다크 모드(테마 설정).
- **추후 확장:** 서버 계정 기반 클라우드 백업·동기화.

## 5. 공통 UI 요소

여러 화면에서 재사용하는 UI 요소를 정의합니다.

| 요소 | 설명 |
|------|------|
| **상태바 헤더** | 각 화면 상단의 시간 · 상태 아이콘과 화면 제목 영역 |
| **둥근 카드(Rounded Card)** | 콘텐츠를 담는 기본 컨테이너. 넉넉한 여백과 부드러운 그림자 |
| **진행률 바 / 게이지** | 달성률 · 다음 보상 진행 등을 표현하는 선형 진행 바 |
| **원형 달성 링** | 캘린더 등에서 날짜별 달성률을 원형으로 표현 |
| **마스코트(곰 캐릭터)** | 응원 · 칭찬의 정서적 경험을 전달하는 공통 캐릭터 |
| **응원/칭찬 말풍선** | 캐릭터와 함께 노출되는 격려 메시지 카드 |
| **페이지 인디케이터** | 현재 화면 위치를 나타내는 하단 점 표시 |
| **상단 네비게이션** | 5개 화면으로 바로 이동하는 아이콘 내비게이션 |
| **배지 아이콘** | 획득 성취를 표현하는 원형 배지 |
| **파스텔 컬러 팔레트** | 보라색 포인트 + 파스텔 톤 기반 색상 체계 |

## 6. MVP 단계별 구현 범위

PRD의 기능 범위([PRD.md](PRD.md) 6장)를 화면 단위로 매핑한 구현 우선순위입니다.

### MVP-Core (최우선)

습관 형성과 응원 경험의 뼈대가 되는 최소 필수 범위입니다.

- **오늘 화면:** 캐릭터 표시 · 응원 메시지, 할 일 체크리스트, 달성률/완료 피드백.
- **보상 화면:** 기본 보상(배지 · 코인) 획득, 칭찬 메시지.
- **통계 화면:** 연속 기록(스트릭) 시각화.
- **설정 화면:** 로컬 데이터 저장 기반 기본 설정, 앱 정보.

### MVP-Next (다음 단계)

핵심 경험을 강화하고 성장 재미를 더하는 범위입니다.

- **통계 화면:** 통계 및 성장 그래프(달성률 추이 · 주간 막대 · 전체 완료율).
- **캘린더 화면:** 캘린더 기록 조회 전체(월간 그리드 · 날짜별 달성 링 · 선택 날짜 상세).
- **오늘/보상 화면:** 레벨 · 캐릭터 성장 반영.
- **설정 화면:** 목표 템플릿 관리, 다크 모드(테마 설정).

### 추후 확장 (장기 로드맵)

제품 안정화 이후 검토하는 범위입니다.

- **보상/설정 화면:** 코인 상점(캐릭터 · 테마 구매), 서버 계정 기반 클라우드 백업 · 동기화.
- (그 외 홈 위젯, 소셜/랭킹 등은 [PRD.md](PRD.md) 참고)
