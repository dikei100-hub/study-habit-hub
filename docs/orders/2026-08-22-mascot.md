## 5. 고정 문자열

오늘 화면 상단 인사말. **3단계로 바꾼다.**

| 단계 | 조건 | 제목 | 부제 |
|---|---|---|---|
| 시작 전 | `rate === 0` | `오늘도 화이팅!` | `조금씩 해내는 하루가 쌓여요 💜` |
| 진행 중 | `0 < rate < 100` | `잘하고 있어요!` | `이 기세로 끝까지 가봐요 💜` |
| 목표 달성 | `rate === 100` | `오늘 목표 달성! 🎉` | `정말 최고예요, 오늘 하루 수고했어요 💜` |

- 시작 전·목표 달성 문구는 **지금 있는 것 그대로**다. 진행 중만 새로 생긴다.

## 6. 구현

### 커밋 1 — 기능: 마스코트 컴포넌트 신설

허용 파일: `src/components/app/Screen.tsx`, `public/char_*.png`(이미 있는 4개),
이 지시서 파일

#### `Screen.tsx` 에 `Mascot` 을 추가한다

- props: `kind: "hello" | "good" | "congrats" | "graduate"`, `size?: number`(기본 96)
- `kind` → 파일 경로 매핑을 **컴포넌트 안 한 곳**에 둔다.
  화면들이 `/char_hello.png` 같은 경로를 직접 쓰지 않게 한다.
- 겉모습은 `MascotSlot` 과 같은 **원형 컨테이너**를 유지하되, 배경을 회색
  placeholder(`bg-muted`)가 아니라 **연분홍(`bg-blush`)** 으로 한다.
  `CrossTrack_AppSpec.md` 2절의 "마스코트 배경에 연분홍" 을 따른다.
- 이미지는 원 안에 꽉 차지 않게 약간 여유를 준다. 원 지름의 **약 82%** 로 두고
  가운데 정렬. 꽉 채우면 귀·왕관이 원에 잘린 것처럼 보인다.
- 장식 요소이므로 `alt=""` + `aria-hidden` 으로 스크린리더에서 뺀다.
- 새 색·새 그림자를 만들지 말 것. 등록된 토큰만 쓴다.

#### `MascotSlot` 은 이 커밋에서 **지우지 말 것**

아직 5곳이 쓰고 있다. 커밋 2에서 교체를 마친 뒤 지운다.
**각 커밋이 그 자체로 컴파일되어야 한다.**

#### 이미지 4개를 이 커밋에 포함한다

경로를 명시해 `git add` 할 것. `public/drawable*` 는 절대 포함하지 말 것.

### 커밋 2 — 기능: 화면 5곳 연결과 오늘 인사말 3단계

허용 파일: `src/routes/index.tsx`, `src/routes/stats.tsx`,
`src/routes/rewards.tsx`, `src/components/app/ListSheet.tsx`,
`src/components/app/Screen.tsx`

#### 자리별 매핑 (`CrossTrack_Assets.md` 1절 기준)

| 파일 | 위치 | `kind` | `size` |
|---|---|---|---|
| `index.tsx` | 상단 캐릭터 | **달성률 3단계** | 96 (기본) |
| `stats.tsx` | "꾸준함이 힘이에요!" 카드 | `graduate` | 84 |
| `rewards.tsx` | 상단 칭찬 카드 | `congrats` | 88 |
| `rewards.tsx` | 아래쪽 | `graduate` | 72 |
| `ListSheet.tsx` | 시트 상단 | `hello` | 64 |

**`size` 값은 지금 것을 그대로 유지한다.** 바꾸지 말 것.

#### `index.tsx` — 3단계

- 마스코트: `rate === 0` → `hello`, `0 < rate < 100` → `good`, `rate === 100` → `congrats`
- 인사말: 5절 표대로 **제목·부제 모두 3단계**로.
- 단계 판정을 **한 곳에서** 하고 마스코트와 문구가 그 결과를 함께 쓰게 한다.
  두 군데서 따로 `rate` 를 비교하면 나중에 경계를 바꿀 때 어긋난다.
- 그 외 레이아웃·여백·달성률 카드·할 일 목록은 **한 줄도 바꾸지 말 것.**

#### `Screen.tsx` — `MascotSlot` 제거

교체가 끝났으므로 지운다. `git grep -n "MascotSlot" -- src/` 가 비어야 한다.

### 커밋 3 — 문서: 마스코트 반영 상태 갱신

허용 파일: `docs/CoreRules.md`, `docs/sessions/2026-08-22.md`

#### 7장 placeholder 문구 갱신

지금은 "마스코트·배지·트로피 이미지는 원본이 확보됐으나 아직 화면에 붙이지
않았고, 현재는 원형 placeholder 로 자리만 잡는다" 는 취지로 되어 있다.
**마스코트는 반영됐고 배지·트로피는 아직**이라는 상태로 고친다.

함께 적을 것.

> - 마스코트는 달성률 3단계로 바뀐다: 0% `hello` / 1~99% `good` / 100% `congrats`.
>   통계·보상 아래쪽은 `graduate`, 리스트 관리 시트는 `hello`.
> - 이미지는 256×256 투명 PNG. 안드로이드 원본에서 배경을 걷고 여백을 잘라
>   크기를 맞춘 것이다(원본 합계 4.7MB → 280KB).
> - 화면이 파일 경로를 직접 쓰지 않는다. `Mascot` 컴포넌트의 `kind` 로만 고른다.

#### 10장 갱신

"해결됨" 표에 한 줄 추가. 실제 해시로 적을 것.

## 7. 검증

빌드하지 말 것. dev 서버도 띄우지 말 것. **화면 확인은 사용자가 한다.**

| # | 확인 | 방법 |
|---|------|------|
| 1 | 이미지 4개가 `public/` 에 실재하고 256×256 | 파일 확인 |
| 2 | 커밋에 이미지 4개가 들어감 | `git show --stat` |
| 3 | `public/drawable*` 가 커밋에 없음 | `git diff --name-only \| grep drawable` |
| 4 | `MascotSlot` 이 저장소에서 사라짐 | `git grep -n "MascotSlot" -- src/` |
| 5 | 화면이 이미지 경로를 직접 쓰지 않음 | `git grep -n "char_" -- src/` 가 `Screen.tsx` 한 곳뿐 |
| 6 | 3단계 경계 | `rate` 0 / 1 / 50 / 99 / 100 에서 `kind` 와 문구가 표대로인지 |
| 7 | `npx tsc --noEmit` | 통과 |
| 8 | `npm run lint` | 기존 CRLF 외 새 오류 없음 |

6번은 **경계값이 틀리기 쉽다.** `rate === 1` 과 `rate === 99` 가 둘 다 `good`
이어야 하고, `rate === 0` 이 `good` 으로 새면 안 된다.

## 10. 사용자에게 안내할 것 (보고에 포함)

화면에서 볼 것.

- 오늘 화면에서 할 일을 **하나 체크** → 마스코트가 `hello` 에서 `good` 으로,
  문구가 `잘하고 있어요!` 로 바뀌는지
- **전부 체크** → `congrats` 와 `오늘 목표 달성! 🎉`
- **체크 해제** → 다시 `hello` 로 돌아오는지
- 통계·보상·리스트 관리 시트의 마스코트가 각각 제자리인지

> `char_good` 과 `char_congrats` 는 다른 둘과 그림체가 조금 다르다(외곽선이
> 굵고 색이 진하다). 한 자리에서 연달아 바뀌므로 전환할 때 눈에 띌 수 있다.
> 어색하면 사용자에게 알리도록 안내할 것.
