## 7. 구현

### 커밋 1 — 기능: 배지·트로피 이미지와 표시 컴포넌트

허용 파일: `src/components/app/Screen.tsx`, `public/badge_*.png`,
`public/trophy_*.png`, 이 지시서 파일

- `Badge` 컴포넌트를 만든다. props: `code: BadgeCode`, `earned: boolean`, `size?: number`(기본 72).
  - **`code → 경로` 매핑을 이 파일 한 곳에 둔다.** 3절 표대로.
    화면이 `/badge_*.png` 를 직접 쓰지 않게 한다. `Mascot` 의 선례를 따를 것.
  - **미획득은 흐리게.** 회색조 + 낮은 불투명도로 "잠금" 을 표현한다.
    숨기지 않는다 — 목표가 보여야 동기가 된다(`CoreRules` 8장).
  - 장식이므로 `alt=""` + `aria-hidden`.
- `Trophy` 컴포넌트도 같은 방식으로 만든다. props: `id: "bronze"|"silver"|"gold"`, `size?`.
  - lucide 의 `Trophy` 아이콘과 이름이 겹치면 import 별칭으로 피할 것.
- `BadgeSlot` 은 이 커밋에서 **지우지 말 것.** 커밋 2에서 교체한 뒤 지운다.
  **각 커밋이 그 자체로 컴파일되어야 한다.**
- 이미지 15개를 이 커밋에 포함한다. 경로를 명시해 `git add` 할 것.

### 커밋 3 — 기능: 배지 획득 축하

허용 파일: `src/lib/storage.ts`, `src/state/StudyStore.tsx`,
`src/components/app/Screen.tsx`, `src/components/app/BadgeCelebration.tsx`(신규)

#### 어떻게 "새로 받았다" 를 아는가

리듀서 상태에 **저장하지 않는 임시 값**을 하나 둔다.

- 상태에 `justEarned: BadgeCode[]` 를 추가한다.
- `settleRewards` 가 새 배지를 돌려주면 그 코드들을 `justEarned` 에 담는다.
- 액션 `dismissBadgeCelebration` 으로 빈 배열로 되돌린다.
- **`hydrate` 직후의 정산에서는 담지 않는다.** 앱을 열자마자 옛 배지로 축하가
  뜨면 안 된다. 축하는 **이번 조작으로 새로 받은 것**에만 뜬다.

★ **`saveState` 가 `justEarned` 를 저장하지 않게 한다.**
지금은 리듀서 상태를 통째로 넘기고 있을 가능성이 크다.
`{ todosByDate, templates, rewards }` **세 개만 명시적으로 골라** 넘기도록 고칠 것.
이렇게 해두면 앞으로 임시 값을 더 두어도 저장소가 오염되지 않는다.

#### `BadgeCelebration.tsx` 신규

- **`ListSheet` 의 오버레이 구조를 따른다.** 새 패턴을 발명하지 말 것.
  다만 시트가 아니라 **화면 가운데 팝업**이다.
- 내용: 받은 배지 이미지(들) + 6절 문구 + 부제.
  - 1개면 `{배지이름} 획득!`, 여러 개면 `배지 {n}개 획득!` 과 이미지를 나란히.
- **약 2.5초 뒤 자동으로 닫힌다.** 바깥을 눌러도 닫힌다.
  닫힐 때 `dismissBadgeCelebration` 을 부른다.
- 타이머는 언마운트 시 반드시 정리할 것.
- `prefers-reduced-motion` 을 쓰는 사용자에겐 애니메이션을 줄일 것.

#### `Screen.tsx` 에 연결

- `Screen` 은 네 화면이 모두 쓰므로 여기 두면 **어느 탭에 있든 축하가 뜬다.**
  오늘 화면에서 체크하다 배지를 받는 것이 가장 흔한 경로다.
- `justEarned` 가 비어 있으면 아무것도 그리지 않는다.
