## 3. 배경

`createSeedTodos()` 가 **과거 10일치 가짜 기록**을 만든다. 조사 결과
`2026-08-05 ~ 2026-08-18` 에 11개 키가 깔리고, 그중 넷은 100% 달성으로 되어 있다.

그래서 지금 스트릭·달성률·통계·캘린더가 **전부 가짜 데이터 위에서 돌고 있다.**
설정 시트로 초기화해도 이 기록이 다시 깔려서 "안 지워졌다"로 보인다. 초기화는
정상 동작이고, 시드가 문제다.

`StudyMate_앱개발_플레이북.md` 6장 릴리스 체크리스트의 첫 줄이
**"개발용 SEED/디버그 플래그 전부 false — 가짜 통계가 실사용자에게 나가면 안 됨"**
이다. 안드로이드판에서 이미 겪은 함정이고 웹이 같은 자리에 서 있다.

다만 통계·캘린더를 만들 때는 가짜 데이터가 있어야 확인이 쉽다. 그래서 **지우는
것이 아니라 기본이 꺼진 플래그 뒤로 옮긴다.**

## 6. 구현

### 커밋 1 — 수정: 시드에서 가짜 과거 기록 제거

허용 파일: `src/lib/seed.ts`, `src/lib/devSeed.ts`(신규), 이 지시서 파일

#### `src/lib/devSeed.ts` 신규

- 상수 `DEV_SEED = false` 를 export 한다. **기본은 반드시 `false`.**
- 지금 `seed.ts` 에 있는 가짜 데이터 생성 로직을 이 파일로 **옮긴다.**
  `tasksForRate`, `monthRecords`·`calendarMonth` 를 읽어 과거 날짜를 깔던 부분,
  `todayTasks` 로 오늘을 덮어쓰던 부분 전부.
- 함수 이름은 `createDevSeedTodos()` 로 한다.
- 파일 맨 위에 주석으로 용도를 남긴다.

> **개발용 가짜 데이터.** 통계·캘린더 화면을 만들 때 빈 화면이면 확인이
> 어려워서 둔다. `DEV_SEED` 는 **항상 `false` 로 커밋한다.** 켠 채로
> 내보내면 실사용자에게 가짜 기록이 보인다.

#### `src/lib/seed.ts`

- `createSeedTodos()` 를 아래 동작으로 바꾼다.
  - `DEV_SEED` 가 `true` 면 `createDevSeedTodos()` 결과를 반환한다.
  - 아니면 **오늘 날짜 하나만** 만든다. 내용은 템플릿 3개가 미완료로 깔린 것.
- ★ **오늘 목록을 손으로 만들지 말 것.** `fillFromTemplate({}, today, templates)`
  를 그대로 쓴다. 새 날 채우기와 첫 실행이 같은 함수를 지나야
  `todoIdFor` 형식·정렬·미완료 상태가 어긋날 수 없다. (`CoreRules` 5장)
- `monthRecords`·`calendarMonth`·`todayTasks` import 를 제거한다.
  `type Task` import 는 남는지 확인하고 필요 없으면 함께 정리한다.
- `tasksForRate` 는 `devSeed.ts` 로 옮겼으므로 이 파일에서 제거한다.
- `createSeedTemplates()` 는 **그대로 둔다.** 템플릿 3개는 유지한다.

#### `src/mockData.ts`

- **손대지 말 것.** `devSeed.ts` 가 계속 읽고, `rewards.tsx`·`stats.tsx` 도 쓴다.

### 커밋 2 — 문서: 첫 실행 상태와 개발용 플래그 명시

허용 파일: `docs/CoreRules.md`, `docs/sessions/2026-08-22.md`

#### 9장에 "첫 실행 상태" 절을 추가

> 저장된 값이 없을 때 만들어지는 상태는 아래가 전부다.
>
> - 리스트 관리 템플릿 3개
> - **오늘 날짜의 할 일 3개, 모두 미완료** (템플릿에서 깔린 것)
> - **과거 기록 0건.** 캘린더는 전부 `-`, 스트릭 0, 통계 0%
>
> 오늘 목록은 손으로 만들지 않고 새 날 채우기와 **같은 함수**를 지난다(5장).
> 첫 실행과 이후 날짜가 다른 경로로 만들어지면 id 형식·정렬이 어긋난다.
>
> **개발용 가짜 데이터:** `src/lib/devSeed.ts` 의 `DEV_SEED`. 통계·캘린더를
> 만들 때 켜서 쓴다. **항상 `false` 로 커밋한다.** 켠 채로 내보내면 실사용자에게
> 가짜 기록이 보인다.

#### 10장 갱신

"해결됨" 표에 한 줄 추가.

| 시드가 과거 10일치 가짜 기록을 만들어 스트릭·통계가 전부 가짜 위에서 돌았음 | 이번 커밋 |

실제 해시로 적을 것. `이번 사이클` 같은 표현을 남기지 말 것.

#### `SettingsSheet.tsx` 주석 — 손대지 말 것

"리로드하면 `loadState` 가 시드 상태를 새로 만든다"는 여전히 사실이다.
