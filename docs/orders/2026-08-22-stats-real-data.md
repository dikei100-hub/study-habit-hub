## 3. 배경

시드에서 가짜 기록을 걷어내자 통계 화면에 남은 하드코딩이 드러났다.
확인해 보니 이 화면은 이미 대부분 실데이터로 돌고 있고, 가짜는 **두 곳뿐**이다.

| 위치 | 현재 | 문제 |
|---|---|---|
| `stats.tsx:60` | `▲ 이전 7일보다 {weekSummary.diff}%` | 값 `73` 고정. 화살표·초록색도 고정이라 **항상 상승으로 보인다** |
| `stats.tsx:67` | `{monthSummary.label}` | `"8월 달성률"` 고정. 9월이 되어도 8월이라고 나온다 |

### 정할 것 — "이전 7일"의 뜻이 흐리다

카드 제목은 **"이번 주 달성률"**(일~토 달력 주간, `weekKeys`)인데 증감 문구는
**"이전 7일"**이다. 도넛과 증감이 서로 다른 창을 재고 있다.

**이렇게 맞춘다:** 도넛은 그대로 이번 주(달력 주간)를 재고, 증감은
**"이번 주 경과분 vs 지난주 같은 경과분"** 을 비교한다. 문구도 `지난주보다` 로 바꾼다.
그러면 도넛과 증감이 같은 것을 잰다.

- 오늘이 수요일이면 → 이번 주 일~수 **4일** vs 지난주 일~수 **4일**
- 아직 지나지 않은 요일은 양쪽 모두에서 뺀다. 그래야 공정한 비교다.

> 표시 문구는 **상태에서 파생**시킨다. 화면이 직접 계산하면
> `CrossTrack_Lessons.md` 2-6 이 지적한 "모순되는 두 계산 경로" 가 생긴다.
> 안드로이드판에서 실제로 "오늘 이미 달성했는데 끊겼어요" 가 뜬 원인이다.

## 5. 고정 문자열

화면에 나가는 한글. 아래 그대로 쓸 것.

| 상태 | 문구 |
|---|---|
| 상승 | `▲ 지난주보다 {n}%` |
| 하락 | `▼ 지난주보다 {n}%` |
| 동일 | `지난주와 같아요` |
| 비교 불가 | `지난주 기록이 없어요` |
| 월 라벨 | `{월}월 달성률` (예: `8월 달성률`) |

- 하락일 때 `{n}` 은 **절댓값**이다. `▼ 지난주보다 -12%` 처럼 쓰지 말 것.
- 나머지 문구(`매달 새롭게 시작해요`, `꾸준함이 힘이에요!` 등)는 손대지 말 것.

## 6. 구현

### 커밋 1 — 수정: 이번 주 증감과 월 라벨을 실계산으로

허용 파일: `src/state/StudyStore.tsx`, `src/routes/stats.tsx`,
`src/styles.css`, 이 지시서 파일

#### `src/state/StudyStore.tsx` — 셀렉터 추가

- **리듀서·액션·저장 구조를 건드리지 말 것.** 읽기 전용 파생값만 추가한다.
- `weekDiff` 를 추가한다. 타입은 이런 모양이다.

```
weekDiff: { value: number; kind: "up" | "down" | "same" | "none" }
```

계산 방법:

1. **이번 주 경과 구간** = `weekKeys(today)` 중 `today` 이하인 키들.
2. **지난주 같은 구간** = 위 각 키에서 7일을 뺀 키들.
3. 두 구간을 각각 `rangeStats` 로 집계해 `rate` 를 얻는다.
4. 판정
   - 지난주 `total === 0` **또는** 이번 주 `total === 0` → `kind: "none"`, `value: 0`
   - 그 외 `diff = 이번주.rate − 지난주.rate`
     - `diff > 0` → `"up"`, `value: diff`
     - `diff < 0` → `"down"`, `value: Math.abs(diff)`
     - `diff === 0` → `"same"`, `value: 0`
- `monthLabel: string` 을 추가한다. `today` 의 월에서 만든다 (`{월}월 달성률`).
- 기존 `weekStats`·`monthStats`·`last7Days`·`streak` 는 **그대로 둔다.**

#### `src/styles.css` — 하락 색 토큰 추가

- `--up: #2e9e5b` 만 있고 하락 색이 없다. 같은 자리·같은 방식으로 추가한다.
  - `--down: #d1604c;` (부드러운 코랄)
  - `--color-down: var(--down);`
- **글자색 전용**이다. 배경으로 쓰지 말 것.
- 다른 색을 건드리지 말 것.

#### `src/routes/stats.tsx` — 연결만

- `import { monthSummary, weekSummary } from "@/mockData";` 를 **제거**한다.
- 증감 줄을 `weekDiff` 로 렌더한다. 5절 고정 문자열대로.
  - `up` → `text-up`, `down` → `text-down`
  - `same`·`none` → `text-muted-foreground`
  - **화살표는 `up`·`down` 일 때만** 붙인다. `same`·`none` 에는 붙이지 말 것.
- 월 라벨을 `monthLabel` 로 바꾼다.
- **그 외에는 한 줄도 바꾸지 말 것.** 레이아웃·여백·다른 카드·막대그래프·도넛 무수정.

#### 8장 또는 적절한 자리에 "통계 표시 규칙" 을 짧게 추가

> - **이번 주 달성률**은 일~토 달력 주간을 잰다. 아직 지나지 않은 날은 기록이
>   없으므로 분모에 들어가지 않는다.
> - **증감**은 "이번 주 경과분 vs 지난주 같은 경과분" 을 비교한다.
>   오늘이 수요일이면 양쪽 다 일~수 4일씩이다. 도넛과 증감이 같은 것을 재도록.
> - 어느 한쪽이라도 기록이 없으면 증감을 표시하지 않는다.
> - 표시 문구는 **상태에서 파생**시킨다. 화면이 직접 계산하면 서로 모순되는
>   두 경로가 생긴다.

#### 10장 갱신

"남은 이슈" 1번(통계 하드코딩)을 "해결됨" 표로 옮긴다. 실제 해시로 적을 것.
남은 이슈 번호를 다시 매긴다.

## 7. 검증

`rolldown` 으로 번들해 Node 에서 확인한다. **dev 서버를 띄우지 말 것.**

| # | 케이스 | 기대 |
|---|--------|------|
| 1 | 이번 주·지난주 모두 기록 없음 | `kind: "none"` |
| 2 | 지난주만 기록 있음 | `kind: "none"` |
| 3 | 이번 주 100%, 지난주 50% | `kind: "up"`, `value: 50` |
| 4 | 이번 주 50%, 지난주 100% | `kind: "down"`, **`value: 50`** (음수 아님) |
| 5 | 양쪽 같은 비율 | `kind: "same"`, `value: 0` |
| 6 | 비교 구간 길이 | 이번 주 경과 키 수 == 지난주 비교 키 수 |
| 7 | 지난주 키가 실제로 −7일 | 키 목록을 인용해 보일 것 |
| 8 | `monthLabel` | 오늘이 8월이면 `8월 달성률` |
| 9 | `git grep -n "mockData" -- src/routes/stats.tsx` | 결과 없음 |
| 10 | `npx tsc --noEmit` | 통과 |
| 11 | `npm run lint` | 기존 CRLF 외 새 오류 없음 |

4번이 핵심이다. 절댓값 처리를 빠뜨리면 화면에 `▼ 지난주보다 -50%` 가 나온다.

6번은 **주 경계**에서 틀리기 쉽다. 오늘이 일요일(경과 1일)일 때와
토요일(경과 7일)일 때를 각각 확인할 것.
